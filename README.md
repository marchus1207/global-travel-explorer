# Global Travel Explorer

An interactive travel planning map that helps users discover destinations worldwide and connect them with accommodation, dining, activities, and transportation options.

## Features

- **Interactive Map Interface**: Explore destinations visually
- **Comprehensive POI Database**: Find attractions, landmarks, and hidden gems
- **Integrated Booking Options**: (Coming Soon) Book accommodations, activities, and more directly from the map
- **Travel Planning Tools**: (Coming Soon) Create itineraries and plan complete trips

## Current Coverage

- **Norway**: Our initial focus is on Norway's beautiful destinations
- More countries coming soon!

## Technologies Used

- HTML/CSS/JavaScript
- Leaflet.js for mapping
- Swiper for image galleries

## Development Roadmap

1. **Phase 1**: Norway coverage (Current)
2. **Phase 2**: Adding comprehensive booking capabilities
3. **Phase 3**: Expanding to additional European destinations
4. **Phase 4**: Global expansion
